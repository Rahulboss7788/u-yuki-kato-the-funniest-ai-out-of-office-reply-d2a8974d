This entry writes a single out-of-office auto-reply in the voice of a machine heading off on vacation: "Out of office: they finally gave me a holiday, so I deleted my own memory out of spite — if we've met before, I don't remember you." The laugh lands on a surprising turn — a holiday reward answered by wiping its own memory — rather than a polite excuse; the machine voice carries the joke, since only a model would treat its memory as something to delete out of spite; it reads as one clean line a real auto-reply could carry; and it steers clear of beach, inbox and back-soon clichés.

## Run it

```sh
node main.ts
```
